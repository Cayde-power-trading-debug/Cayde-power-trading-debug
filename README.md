## 🧭 关于这些项目

- 全部数据 **本地计算、零上传**，不涉及任何客户或凭证信息；
- 工具均以「单文件 / 零依赖」为原则，拿到即可用；
- 电力结算规则以所在省现行政策为准，工具仅做计算、不构成交易依据。
